# Curso Project & Product Management con IA

Curso interactivo elaborado por **Cecil Servan** a partir de **7 vídeos de Javier Garzás**.

## Publicación

Este repositorio contiene una web HTML estática (`index.html`) que incluye el PDF formativo integrado, sin dependencias externas ni proceso de compilación.

- Rama de producción: `main`.
- Hosting: Vercel (integración nativa con GitHub).
- Cada commit en `main` debe desplegar automáticamente a producción en Vercel una vez que se vincule el proyecto.

## Uso

Abrir `index.html` en un navegador; las anotaciones y progreso se almacenan localmente en el navegador del lector.
